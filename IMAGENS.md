# Instruções de Imagens

Para que o site exiba corretamente as imagens do hero carousel, copie as 5 imagens que você enviou para a pasta `public/images/` com os seguintes nomes:

1. `consultoria.jpg` - Imagem da consultoria online (COMECE SUA MUDANÇA HOJE!)
2. `plano1.jpg` - Imagem do Plano 1 Top
3. `plano2.jpg` - Imagem do Plano 2 Master
4. `plano3.jpg` - Imagem do Plano 3 Master Avançado
5. `logo.jpg` - Logo Dário Lopes Personal (opcional, para uso futuro)

## Como copiar as imagens

Se as imagens estiverem na pasta de Downloads ou Desktop, basta copiá-las para:
```
c:\Users\José Silva\Documents\dario-personal\public\images\
```

## Alternativa: usar outras imagens

Se preferir usar outras imagens de stock de academia/fitness, renomeie-as conforme a lista acima e coloque na mesma pasta.

O site já está configurado para carregar essas imagens automaticamente no hero carousel.
